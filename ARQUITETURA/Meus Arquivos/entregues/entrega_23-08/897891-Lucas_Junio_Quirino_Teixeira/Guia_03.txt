03.) Determinar os valores positivos equivalentes aos complementos de dois indicados

03a.)

a.) 10101(2) = X(10)

O valor está representado em complemento de 2 com 5 bits.

Para encontrar o valor positivo equivalente,
primeiro subtraímos 1:

10101
    1
-----
10100

Depois invertemos cada bit:

10100
01011

01011(2)

= 0*2⁴ + 1*2³ + 0*2² + 1*2¹ + 1*2⁰
=     0 + 8 + 0 + 2 + 1
=           11(10)

resultado:

10101(2) em complemento de 2 representa -11(10)
valor positivo equivalente = 11(10)



b.) 110111(2) = X(10)

Primeiro subtraímos 1:

110111 - 1 = 110110

Depois invertemos os bits:

110110
001001

001001(2) = 8 + 1 = 9(10)

resultado:

110111(2) em complemento de 2 representa -9(10)
valor positivo equivalente = 9(10)



c.) 100110(2) = X(2)

100110 - 1 = 100101

Depois invertemos os bits:

011010

resultado:

100110(2) em complemento de 2 possui valor positivo equivalente:

04.) Fazer as operações indicadas mediante uso de complemento de dois

04a.)

a.) 11101(2) - 1011(2) = X(2)

Primeiro ajustamos os dois valores para a mesma quantidade de bits,
incluindo um bit para sinal:

11101(2) = 011101(2)
1011(2)  = 001011(2)

Agora substituímos o subtraendo pelo complemento de 2.

C1:

001011
110100

Somando 1:

110100
     1
------
110101

Entao:

  011101
+ 110101
--------
1 010010

O bit que excedeu os 6 bits é descartado:

010010(2)

resultado:

11101(2) - 1011(2) = 10010(2)



b.) 101,1011(2) - 10,01(2) = X(2)

Primeiro alinhamos as vírgulas e completamos as casas:

101,1011(2)
010,0100(2)

Incluindo o bit de sinal:

0 101,1011
0 010,0100

Calculamos o complemento de 2 do subtraendo:

0 010,0100
1 101,1011   <- complemento de 1
          1
-----------
1 101,1100   <- complemento de 2

Somando:

  0 101,1011
+ 1 101,1100
------------
1 0 011,0111

Descartamos o bit que excedeu a representação:

0 011,0111

resultado:

101,1011(2) - 10,01(2) = 11,0111(2)

e.) A4C(16) - B7F(16) = X(16)

Primeiro convertemos os dois valores para binário
e adicionamos um bit para sinal:

A4C(16) = 1010 0100 1100(2)

0 1010 0100 1100
0 1011 0111 1111

Calculamos o complemento de 2 do subtraendo:

                1
-----------------

  0 1010 0100 1100
+ 1 0100 1000 0001
-------------------

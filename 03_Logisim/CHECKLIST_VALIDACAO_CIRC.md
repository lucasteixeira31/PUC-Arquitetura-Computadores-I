# Checklist de Validação de Arquivos .circ

Um arquivo somente pode ser movido para:

01_Referencias_Circ/01_Validados

após completar todos os testes.

---

# 1. Arquivo

[ ] Nome correto

[ ] Extensão .circ

[ ] Arquivo abre no Logisim

[ ] Não apresenta erro de carregamento

---

# 2. Estrutura

[ ] Componentes corretos

[ ] Entradas identificadas

[ ] Saídas identificadas

[ ] Organização visual adequada

[ ] Sem componentes quebrados

---

# 3. Ligações

[ ] Todos os fios conectados

[ ] Sem conexões acidentais

[ ] Bits configurados corretamente

[ ] Fluxo lógico conferido

---

# 4. Funcionamento

[ ] Testes realizados

[ ] Entradas testadas

[ ] Saídas conferidas

[ ] Resultado corresponde ao esperado

---

# 5. Compatibilidade

[ ] Arquivo salvo novamente

[ ] Arquivo reaberto após salvar

[ ] Funcionamento permanece correto

---

# Registro obrigatório

Após validação criar:

04_Registros_de_Validacao/NOME_DO_CIRCUITO.md


Informar:

- nome do circuito;
- data;
- versão do Logisim;
- testes realizados;
- resultado final.

# PUC - Arquitetura de Computadores I

Repositório técnico da disciplina PUC - Arquitetura de Computadores I.

## Objetivos

- organizar arquivos técnicos;
- controlar versões;
- armazenar circuitos Logisim;
- registrar validações;
- manter histórico de desenvolvimento.

## Estrutura

### Logisim

Arquivos `.circ` organizados por:

- referências validadas;
- arquivos que abrem sem validação;
- arquivos com problemas;
- projetos desenvolvidos.

## Regra de validação

Um arquivo somente é considerado validado após:

1. abertura no Logisim 2.16.2.2.jar;
2. compatibilidade com `source="2.7.1"`;
3. componentes corretos;
4. conexões corretas;
5. funcionamento testado.

04.) Fazer as conversões de base entre as bases indicadas por agrupamento:

a.) 10011(2) = X(4)

Em base 4, agrupamos em grupos de dois bits, da direita para a esquerda:

1  00  11

A primeira casa ficou incompleta, completamos com 0 à esquerda:

01  00  11

Converter cada grupo:

01(2):

  0*2¹ + 1*2⁰
=  0*2 + 1*1
=    0 + 1
=      1

01(2) = 1

00(2):

  0*2¹ + 0*2⁰
=  0*2 + 0*1
=    0 + 0
=      0

00(2) = 0

11(2):

  1*2¹ + 1*2⁰
=  1*2 + 1*1
=    2 + 1
=      3

11(2) = 3

Lendo os grupos da esquerda para a direita:

01  00  11
1   0   3

resultado:

10011(2) = 103(4)

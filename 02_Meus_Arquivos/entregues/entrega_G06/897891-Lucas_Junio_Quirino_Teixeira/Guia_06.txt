01.) Simplificacao por mapa de Veitch-Karnaugh usando MINTERMOS

05.) Identificacao e simplificacao do circuito usando MINTERMOS

Equacoes intermediarias observadas no circuito:

w8  = y'
w9  = x'
w5  = w8 + w9
w3  = w5'

w6  = x.y
w4  = w6'

w1  = w3.w4

w10 = y.z
w11 = x'
w7  = w10 + w11
w2  = w7'

s = w1 + w2

Substituindo:

w3 = (y' + x')' = x.y
w4 = (x.y)'

Logo:
w1 = (x.y).(x.y)' = 0

Para o segundo ramo:
w2 = (y.z + x')'
   = x.(y.z)'
   = x.(y' + z')

Portanto:
s = x.(y' + z')
s = x.y' + x.z'

Forma canonica por mintermos:
s(x,y,z) = Sum m(4,5,6)

Mapa:
          z
xy       0  1
00       0  0
01       0  0
11       1  0
10       1  1

Simplificacao final:
s = x.y' + x.z'



06.) Identificacao e simplificacao do circuito usando MAXTERMOS

Equacoes intermediarias observadas no circuito:

w8  = y'
w9  = x'
w5  = w8 + w + w9
w3  = w5'

w10 = w'
w6  = x.y.w'
w4  = w6'

w1  = w3.w4

w11 = y.w.z
w12 = x'
w7  = w11 + w12
w2  = w7'

s = w1 + w2

Substituindo:

w3 = (y' + w + x')'
   = x.y.w'

w4 = (x.y.w')'

Logo:
w1 = (x.y.w').(x.y.w')' = 0

Para o segundo ramo:
w2 = (y.w.z + x')'
   = x.(y.w.z)'
   = x.(y' + w' + z')

Portanto:
s = x.(y' + w' + z')

Forma canonica por maxtermos:
s(x,y,w,z) = Pi M(0,1,2,3,4,5,6,7,15)

Mapa:
xy\wz    00  01  11  10
00        0   0   0   0
01        0   0   0   0
11        1   1   0   1
10        1   1   1   1

Simplificacao final em produto de somas:
s = x.(y' + w' + z')

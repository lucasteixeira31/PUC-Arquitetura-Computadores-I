01.) Construir a tabela-verdade para as proposições

01a.)

a.) x . ( y + z' )'

Primeiro avaliamos a expressão interna e aplicamos De Morgan:

(y + z')' = y' . z

Então:

f = x . y' . z

Construindo a tabela-verdade completa:

n    xyz    y    z'    y+z'    (y+z')'    f
0    000     0    1      1         0        0
1    001     0    0      0         1        0
2    010     1    1      1         0        0
3    011     1    0      1         0        0
4    100     0    1      1         0        0
5    101     0    0      0         1        1
6    110     1    1      1         0        0
7    111     1    0      1         0        0

O único resultado igual a 1 ocorre no mintermo 5.

resultado:

f(x,y,z) = x . (y + z')' = x . y' . z = SoP(5)


b.) ( x + y' )' . z

Aplicando De Morgan:

(x + y')' = x' . y

Tabela-verdade:

n    xyz    f
0    000     0
1    001     0
2    010     0
3    011     1
4    100     0
5    101     0
6    110     0
7    111     0

resultado:

f(x,y,z) = x' . y . z = SoP(3)


c.) ( x' . y )' . z'

Aplicando De Morgan:

(x' . y)' = x + y'

Tabela-verdade:

n    xyz    f
0    000     1
1    001     0
2    010     0
3    011     0
4    100     1
5    101     0
6    110     1
7    111     0

resultado:

f(x,y,z) = (x + y') . z' = SoP(0,4,6)


d.) ( x' . y )' . z

Aplicando De Morgan:

(x' . y)' = x + y'

Tabela-verdade:

n    xyz    f
0    000     0
1    001     1
2    010     0
3    011     0
4    100     0
5    101     1
6    110     0
7    111     1

resultado:

f(x,y,z) = (x + y') . z = SoP(1,5,7)


e.) ( x' + y' ) . ( y + z' )'

Aplicando De Morgan:

(y + z')' = y' . z

(x' + y') . y' . z = y' . z

Tabela-verdade:

3    011     0

7    111     0

resultado:

02.) Simplificar as expressões abaixo pelas propriedades da álgebra de Boole

02a.)

a.) x . ( x' + y )'

Aplicando De Morgan:

(x' + y)' = x . y'

Substituindo:

x . (x . y') = x . y'          (idempotência: x.x = x)

resultado:

x . (x' + y)' = x . y'

Verificação pela tabela-verdade:

n    xy    original    simplificada
0    00      0             0
1    01      0             0
2    10      1             1
3    11      0             0


b.) ( x' + y' ) + ( x . y )

x' + y' + x.y
= y' + (x' + x.y)
= y' + (x' + y)                (distributiva/absorção)
= x' + (y' + y)
= x' + 1                       (complementar)
= 1                            (identidade)

resultado:

(x' + y') + (x . y) = 1

Verificação pela tabela-verdade:

n    xy    original    simplificada
0    00      1             1
1    01      1             1
2    10      1             1
3    11      1             1


c.) ( x . y )' . ( x + y' )

(x.y)' = x' + y'               (De Morgan)

(x' + y') . (x + y')
= y' + (x'.x)                  (distributiva)
= y' + 0                       (complementar)
= y'                           (identidade)

resultado:

(x . y)' . (x + y') = y'

Verificação pela tabela-verdade:

n    xy    original    simplificada
0    00      1             1
1    01      0             0
2    10      1             1
3    11      0             0


d.) ( x' . y )' + ( x + y' )'

(x'.y)' = x + y'               (De Morgan)
(x+y')' = x'.y                 (De Morgan)

(x + y') + x'.y
= y' + (x + x'.y)
= y' + (x + y)                 (distributiva/absorção)
= x + (y' + y)
= x + 1
= 1

resultado:

(x' . y)' + (x + y')' = 1

Verificação pela tabela-verdade:

n    xy    original    simplificada
0    00      1             1
1    01      1             1
2    10      1             1
3    11      1             1


e.) ( y + x' + z' ) . ( y' + x + z )'

(y' + x + z)' = y . x' . z'   (De Morgan)

(y + x' + z') . y . x' . z'
= y.x'.z'                      (absorção)

resultado:

(y + x' + z') . (y' + x + z)' = y . x' . z'

Verificação pela tabela-verdade:

n    xyz    original    simplificada
0    000       0             0
1    001       0             0
2    010       1             1
3    011       0             0
4    100       0             0
5    101       0             0
6    110       0             0
7    111       0             0

04.) Montar as expressões PoS equivalentes aos produtos das somas abaixo

04a.)

a.) F(X,Y,Z) = π M (1, 2, 4, 6) = PoS(1,2,4,6)

Os índices indicam os MAXTERMOS em que a função deve valer 0.
Em um MAXTERMO, um bit 0 usa a variável sem negação e um bit 1 usa a variável negada.

M1 = 001 -> (X+Y+Z')
M2 = 010 -> (X+Y'+Z)
M4 = 100 -> (X'+Y+Z)
M6 = 110 -> (X'+Y'+Z)

F = (X+Y+Z') . (X+Y'+Z) . (X'+Y+Z) . (X'+Y'+Z)

1    001    (X+Y+Z') = M1                0
2    010    (X+Y'+Z) = M2                0
3    011    (X+Y'+Z')                    1

PoS(1,2,4,6)

05.) Identificar as expressões SoP e PoS equivalentes às tabelas abaixo

05a.)

a.)

Na forma SoP, usamos os índices em que f = 1.
Na forma PoS, usamos os índices em que f = 0.

SoP(1,3) = x'.y + x.y
PoS(0,2) = (x+y) . (x'+y)

As duas formas são equivalentes a f = y.

resultado:

SoP(1,3)
PoS(0,2)


b.)

SoP(0,2,3) = x'.y' + x.y' + x.y
PoS(1) = (x+y')

As duas formas são equivalentes a f = x + y'.

resultado:

SoP(0,2,3)
PoS(1)


c.)

SoP(0,1,2,6,7) = x'.y'.z' + x'.y'.z + x'.y.z' + x.y.z' + x.y.z
PoS(3,4,5) = (x+y'+z') . (x'+y+z) . (x'+y+z')

resultado:

SoP(0,1,2,6,7)
PoS(3,4,5)


d.)

SoP(0,2,4,6) = x'.y'.z' + x'.y.z' + x.y'.z' + x.y.z'

As duas formas são equivalentes a f = z'.

resultado:
